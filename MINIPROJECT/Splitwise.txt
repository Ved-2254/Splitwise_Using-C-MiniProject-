💸 Splitwise – Expense Sharing System in C++ 💸
🔧 Key Features:
1. Custom Members:
   Add a customizable number of total members to the system.

2. Flexible Bill Sharing:
   Include any number of people in a single bill entry.

3. Individual Total Calculation:
   Automatically compute and display the total spending of each member.

4. Private Bill Records:
   Bills added by a single person are stored privately and can only be accessed by that person.

5. Persistent Data Storage:
   All data is saved and retrieved using file handling for long-term access.

6. Filtering Options:
   Easily filter expenses by category, person, month, or date.

7. Alert System:
   Alert messages notify users about key actions or inconsistencies.

8. Add a feature of a Group.


🧠 Core C++ Concepts Used:
✅ Inheritance

✅ Templates

✅ File Handling

✅ Standard Template Library (STL) – Vectors, Maps, etc.

✅ (Optionally) Polymorphism, Exception Handling, or Operator Overloading can be included as needed.



🏗️ Class Design:

1. Person (public)
Represents a user in the system.

Attributes:
Name
ID
Spendings
History (list of transactions)

Functions:
AddActivity() – Adds a new bill/activity to the person’s record



2. Activity (public)

Represents an expense entry involving multiple members.

Attributes:
NameOfActivity
Category
PersonIDs[] – List of IDs involved in the bill
Bill – Total amount
NoOfPersons – Count of people sharing the expense


3. Total (protected)
Handles overall expense tracking.

Attributes:
TotalSpendings – Aggregated expense total
History – Full list of all activities

💡 Example Object Relationship:
Total contains multiple Person objects.

Each Person can have multiple Activity objects.
